# Ebrahim Youssef — Brand Hub + Product Launchpad (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One static Astro landing page that funnels visitors to Ibrahim's products (NABD, Quran Unified API, Islamic Quiz Game) while the page itself — especially its playable mini-game — proves what he can build.

**Architecture:** Astro 7 static output, all sections as Astro components; a single React island (the game drawer) lazy-loaded on first open. Plain CSS with design tokens (no Tailwind — one page, fully custom design, keeps CSS tiny). Pure game logic (Arabic matching, streak, reducer) as framework-free TS modules under Vitest; UI verified manually. Deploys via the already-connected Cloudflare Pages Git integration (`pnpm run build` → `dist`).

**Tech Stack:** Astro 7, @astrojs/react (already installed), React 19, TypeScript, Vitest, @fontsource-variable/rubik (Latin + Arabic in one family), @astrojs/sitemap, sharp + png-to-ico (icon generation, dev-only).

## Global Constraints

- Positioning line **verbatim** in hero H1: `I help self-taught devs start their front-end journey.`
- Proof caption **verbatim** under the game: `Built to demo RTL input + game-state in Astro.`
- Palette: warm terracotta/amber + gold accent + off-white base + warm charcoal ink. **Never emerald/navy. Never neon.**
- No personal photo anywhere; monogram only (hybrid: square-Kufic-inspired geometry forming "EY").
- No backend, no accounts, no game engine, no leaderboard, no dev-log CMS, no YouTube pipeline (all Phase 2+).
- Persistence: localStorage only.
- Game loop: 7 rounds/session (within the 5–10 spec), ~30s.
- Accessibility: WCAG AA contrast minimum for all text; drawer fully keyboard-operable; `prefers-reduced-motion` respected; skip link.
- Canonical URL: `https://ebrahimyoussef.com` (also in `astro.config` `site`).
- Package manager: pnpm. Runnable via `pnpm run dev`.
- Commits: conventional, no AI trailers.
- Arabic copy authored natively (فصحى), never literal EN→AR translation. Names transliterated, never translated.

## Decisions taken (flagged for review)

1. **Game prompt direction.** Brief says "shows the name… player writes it or taps it." Locked spec: each round shows a one-line **English hint** (e.g. "The first muezzin of Islam"); **Write mode** = type the figure's name in Arabic (RTL input, forgiving normalization, short-name accepted: بلال passes for بلال بن رباح); **Tap mode** = pick from 4 bilingual options (Arabic script + transliteration). Correct → reveal the fact card (richer than the hint, so no self-answer). This keeps "writing/recognition," stays playable for non-Arabic recruiters, and preserves the reveal moment.
2. **No dark mode in v1** — the warm parchment palette *is* the brand; a dark variant dilutes it and doubles QA. Phase 2 candidate.
3. **No Tailwind** — hand-rolled tokens + scoped styles for a one-page custom design.
4. **No analytics in v1** (brief: "wire into analytics later"). Phase 2: Cloudflare Web Analytics one-liner.
5. **Islamic Quiz Game product card** links to the on-page drawer (repo is private; the page *is* the product's home for now).
6. **Generated icons/OG are committed** to `public/` — Cloudflare only runs `astro build`; the sharp script is a dev tool, not a build step.

```ts
export function normalizeArabic(s: string): string {
  return s

    .trim();

export function matchesAnswer(input: string, fig: Figure): boolean {

  if (!n) return false;
```

```ts
const KEY = 'ey-game';
interface Persisted { streak: number; lastPlayed: string; best: number; }

function localDate(d: Date): string {
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}

export function loadStreak(): Persisted {
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) throw new Error('empty');
    const p = JSON.parse(raw) as Persisted;
    if (typeof p.streak !== 'number' || typeof p.lastPlayed !== 'string') throw new Error('shape');
    return { streak: p.streak, lastPlayed: p.lastPlayed, best: p.best ?? 0 };
  } catch {
    return { streak: 0, lastPlayed: '', best: 0 };
  }
}

export function recordSession(score: number, now: Date = new Date()) {
  const prev = loadStreak();
  const today = localDate(now);
  const yesterday = localDate(new Date(now.getTime() - 86_400_000));
  const streak =
    prev.lastPlayed === today ? Math.max(prev.streak, 1)
    : prev.lastPlayed === yesterday ? prev.streak + 1
    : 1;
  const next: Persisted = { streak, lastPlayed: today, best: Math.max(prev.best, score) };
  try { localStorage.setItem(KEY, JSON.stringify(next)); } catch { /* private mode: play, don't persist */ }
  return { streak: next.streak, best: next.best };
}
```

```ts
import type { Figure } from '../../data/figures';

export type Mode = 'tap' | 'write';
export type Phase = 'question' | 'reveal' | 'done';
export interface GameState {
  mode: Mode; phase: Phase; ids: string[]; roundIx: number;
  score: number; lastCorrect: boolean;
}
export type GameAction =
  | { type: 'answer'; correct: boolean }
  | { type: 'next' };

export function initGame(mode: Mode, ids: string[]): GameState {
  return { mode, phase: 'question', ids, roundIx: 0, score: 0, lastCorrect: false };
}

export function gameReducer(s: GameState, a: GameAction): GameState {
  switch (a.type) {
    case 'answer':
      if (s.phase !== 'question') return s;
      return { ...s, phase: 'reveal', lastCorrect: a.correct, score: s.score + (a.correct ? 1 : 0) };
    case 'next':
      if (s.phase !== 'reveal') return s;
      return s.roundIx + 1 >= s.ids.length
        ? { ...s, phase: 'done' }
        : { ...s, phase: 'question', roundIx: s.roundIx + 1 };
  }
}

function shuffle<T>(arr: T[]): T[] {
  const a = [...arr];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

export function pickSession(all: Figure[], n = 7): Figure[] {
  return shuffle(all).slice(0, n);
}

export function pickOptions(target: Figure, all: Figure[]): Figure[] {
  const sameCat = all.filter((f) => f.category === target.category && f.id !== target.id);
  const others = all.filter((f) => f.category !== target.category && f.id !== target.id);
  const distractors = shuffle(sameCat).slice(0, 3);
  while (distractors.length < 3) distractors.push(shuffle(others)[distractors.length]);
  return shuffle([target, ...distractors]);
}
```
